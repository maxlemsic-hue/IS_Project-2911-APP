## How to operate

The local services are running. Open http://localhost:4201 and sign in as local-cashier. Follow README's Local Cashier account section to copy its Windows-encrypted password securely. If starting from stopped servers, start PostgreSQL and run npm.cmd run dev from the repository root.

Search/filter products, select Add to order, adjust valid whole-number quantities and enter customer details. Submit walk-in order saves one Pending Review request. Give the customer its reference and private code before starting another request. Owner/Admin can view it at http://localhost:4200/orders. Customer confirmation and communication use the existing storefront private lookup.

## Remaining limitations and POS Phase 2

POS carts and customer fields are held in memory and clear on logout or reload. Staff login remains restricted to the existing local development architecture. Stock checking and payment verification are manual. Cashier payment recording, gateways, inventory/BOM and offline persistence remain future work.

Recommended POS Phase 2 is cashier payment recording with explicitly assigned permissions and audit, while preserving the established deposit, verification and full-payment release rules.
