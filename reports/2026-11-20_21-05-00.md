- Only browser test orders were added through the existing public API. Test orders are retained. Database migrations and business rules were untouched.

## Running and remaining work

Start PostgreSQL, run npm.cmd run dev, then visit http://localhost:3000. Use category chips to filter real products, select a product, fill in quantity and customer details, and submit. Save the returned reference and access code, then use Track your order to view the private order and existing tools.

Catalog photography is unavailable, so illustrations are placeholders. The hero uses authored print-inspired artwork. The storefront currently supports a single product per request. Implement the real multi-product cart and checkout next, preserving review and confirmation before payment. External font services and new dependencies were unnecessary.
