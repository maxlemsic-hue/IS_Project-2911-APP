## How to use

Start PostgreSQL, then run npm.cmd run dev from the repository root. Open http://localhost:4200/orders and sign in with the existing Owner/Admin account. Select Products & categories or open http://localhost:4200/products.

Create or select a category, add a product and save it. Upload an image with descriptive alternative text, then set Published and Available. Refresh http://localhost:3000 to see it and add it to the cart. Existing review, customer confirmation, manual payment, production and release rules continue to apply.
