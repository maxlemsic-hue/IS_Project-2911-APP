# MVP Step 7 staff login and role authorization

Started 2026-11-20_19-21-38 Asia/Manila (UTC+08:00).

## Work completed

Replaced the shared Admin demo guard with individual loopback staff login and logout. Node crypto scrypt with independent salts hashes passwords. The API stores only a SHA-256 digest of the random session token. The browser uses a SameSite Strict, HTTP-only cookie for the eight-hour session. Sessions expire on the database clock and are revoked on logout or account deactivation. State-changing staff requests require a custom header and explicit CORS, and local login attempts are limited. Staff responses omit password hashes and session tokens.

Owner/Admin manages staff accounts and can review, accept, verify receipts, reply, assign active production users and release paid orders. Production Staff can view assigned production orders, start production and mark Ready. Their API responses omit customer contact details and payment data. Cashier can sign in and see their role. POS, walk-in ordering, cashier payment recording and product management are not yet implemented. Shared-key staff access was removed from the application. The ignored regular local environment was kept untouched.

Important staff order and receipt actions write an audit row in the same transaction as the action. Owner/Admin can view action, actor and timestamp. Existing records are retained without fabricated attribution. Added a password-through-stdin bootstrap script for the first Owner/Admin. Additional accounts are created in Angular Admin.
