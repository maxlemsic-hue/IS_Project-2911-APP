## Demonstration and usage

Run npm.cmd run dev after PostgreSQL is running. Sign in at http://localhost:4200/orders with the existing Owner/Admin account, then open http://localhost:4200/products.

Create a category, choose Add product, enter name and slug, choose the category, enter price/minimum/selling unit and optional description, specifications and attributes. Save the Draft product. Upload an image and description, then choose Published and enable Available. Save and refresh http://localhost:3000.
