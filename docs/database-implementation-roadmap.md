# Incremental database implementation roadmap

Phase 3A: first-stage Prisma schema implemented and initial SQL prepared for review, NOT applied. Phase 3 introduced no migrations. Remaining stages stay recommendations, not execution authorization. All stages require a new approved implementation task, reviewed Prisma models/SQL constraints, targeted tests and documentation. Models listed are proposed logical scope; omit optional tables when the approved feature does not need them.

## Shared migration readiness

Preserve API-only database access and current local PostgreSQL settings. Before any migration, approve field/constraint choices for that stage; separate migration/shadow access from routine app privileges, back up existing data where applicable, review generated SQL and test against a disposable authorized database. Never use reset/db push as a substitute for reviewed history. Validate forward application and recovery strategy; retain existing health behavior. No live business data, authentication secrets or cloud integration is needed for architecture review.

## First migration prepared, not applied

The prepared first migration contains only **Category, Product and ProductAttribute**, plus required enums, checks, indexes, sequence and triggers. FileAsset/ProductImage are excluded and remain Stage 3. See [migration review](catalog-foundation-migration-review.md). No live migration or temporary-database test was authorized. Do not add variants, authentication, financial ledgers, inventory or placeholder business records to make the ERD appear complete. Review all eventual relationships now, implement only a stage's approved working slice.

Stage order is adjustable: file metadata may precede staff if upload attribution is explicitly constrained, and production/inventory may be co-designed, but dependencies and actor/security gates must remain explicit. The complete design is not permission to execute every migration at once. Customer OTP/onboarding, offline POS, managed hosting and provider integrations remain deferred and have no execution date or chosen vendor.
